# Krunker-Tas-Userscript
thank you @thegu5 for open sourcing this


shows where you next bhop will land , lets you record your bhop and replay time, control fps from 1 fps to 1000 , control how many time the game calculates you per second, "perfect" slide hop macro and more

how to use

Browser:
get tampermonkey and setup the two .js scripts
one script records the other replays movement


Desktop :
Download and setup with the installer
